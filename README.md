# TRADE://TERMINAL — Professional Multi-Asset Trading Desk

Bloomberg/ASCII-style high-density financial trading terminal for Crypto, Indonesian Equities (IDX), US Megacaps, Forex, and Commodities.

## Features
- **Technical Candlestick Canvas**: Multi-timeframe (1m, 5m, 15m, 1h, 4h, 1D), EMA 20/50 Ribbons, Volume Histogram, RSI (14) sub-panel.
- **L2 Order Book**: Live depth ladder with visual volume bars and spread calculator.
- **Trading Desk & Blotter**: Paper trading order execution (Buy/Long, Sell/Short, SL/TP) and live position P&L tracker.
- **Multi-Asset Watchlist**: Crypto (BTC, ETH, SOL), IDX (BBCA, BBRI, BMRI, TLKM, ASII, AMMN, IHSG), US Tech (NVDA, AAPL, TSLA, MSFT), FX (USD/IDR, EUR/USD), Metals (Gold, Silver, Oil).
- **World Sessions Clock**: Asian, London, and NY trading sessions with liquidity overlap indicator.
- **Draggable & Resizable Grid**: 12-column Bloomberg tile workspace saved to localStorage.
- **Audio Synthesizer**: Web Audio API retro terminal acoustic feedback.
